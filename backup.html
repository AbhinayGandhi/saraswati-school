Backup

A copy of all school data (students, fees, marks, attendance, settings and more). Do this every month and before closing a year. Uploaded files (photos, attachments) are not included; they stay in Supabase Storage. See BACKUP.md for the full-database backup.

The backup file contains personal data of students and parents. Keep it in a safe place (not on a shared computer, not in a public folder or chat group).
