# Demo data guide
1. Supabase (SCHOOL project only) > SQL Editor > run RESET-DATA.sql after changing 'NO' to 'YES' (erases all students, teachers, fees etc.; keeps classes, settings, fee types, your real logins).
2. Run DEMO-DATA.sql (needs an empty database, so step 1 first).
3. Log in with Demo@12345: principal@, accountant@, reception@, librarian@, teacher01@..teacher20@, parent1@, parent2@, student1@, student2@ (all @demo.example.com).
4. To remove the demo later: run RESET-DATA.sql again (it also deletes the @demo.example.com logins).
